健康・医療に関する注意

BioLog Mobile は日々の健康記録を補助するための個人向けツールです。医療行為、診断、治療、助言を目的としたものではありません。

記録内容、健康状態、医療上の判断は利用者自身の責任で行ってください。体調不良、異常値、健康上の不安がある場合は、医師などの専門家に相談してください。

動作保証、データ保存の注意および責任範囲の詳細は、利用規約 と 免責・重要事項 を確認してください。

PWAについて

BioLog Mobile はPWAです。Webアプリですが、スマホのホーム画面にアイコンを追加して起動できます。App StoreやGoogle Playからインストールするアプリではありません。

記録データは端末のブラウザ内に保存されます。ブラウザのサイトデータを削除すると記録も消えるため、定期的にJSONバックアップを書き出してください。iPhoneでは、Safariで見えるデータとホーム画面版で見えるデータが分かれて見える場合があります。ホーム画面アイコンを削除・再追加する前には、必ずバックアップファイルを保存してください。

1. 起動する

公開URLをスマホのブラウザで開きます。ホーム画面に追加している場合は、BioLog Mobileのアイコンから起動します。

初回利用時と、利用規約またはプライバシーポリシーの同意対象版が改定されたときは、同意画面が表示されます。内容を確認して同意すると、通常機能の起動とオフライン利用の準備が始まります。同意前は健康記録の保存場所を開きません。

同意記録は端末のブラウザ内にだけ保存され、外部サーバーには送信されません。同意しない場合も既存の健康記録は削除されず、同意後も維持されます。起動後に「端末内に保存できます。」と表示されれば、記録を保存できます。

利用規約 / プライバシーポリシー

アプリを更新する

  1. 入力途中の内容がないことを確認します。
  2. 端末をオンラインにします。
  3. 画面右上のライト／ダーク切り替えの下にある「アプリを更新」を押します。
  4. 確認画面で「OK」を押します。
  5. 「更新中...」の表示後、自動的に画面が再読み込みされるまで待ちます。

この操作はアプリ本体のファイルを更新するもので、IndexedDB内の健康記録は削除しません。

2. ホーム画面に追加する

Android

  1. ChromeでBioLog Mobileを開きます。
  2. 右上メニューを開きます。
  3. 「ホーム画面に追加」または「アプリをインストール」を選びます。
  4. 追加後、ホーム画面のアイコンから起動します。

iPhone

  1. SafariでBioLog Mobileを開きます。
  2. 共有ボタンを押します。
  3. 「ホーム画面に追加」を選びます。
  4. 追加後、ホーム画面のアイコンから起動します。

3. 今日の記録を保存する

  1. 「今日」タブを開きます。
  2. 必要な項目を入力します。
  3. 「今日の記録を保存」を押します。

入力できる項目は、体重、体温、収縮期血圧、拡張期血圧、脈拍、体脂肪率、基礎代謝量、筋肉量、食事ログ、行動ログ、メモです。測定値がなくても、食事ログ、行動ログ、メモのいずれかがあれば保存できます。

4. 日付を指定して登録・編集する

  1. 「日付編集」タブを開きます。
  2. 対象日を選びます。
  3. 「読み込む」を押します。
  4. 既存の記録があれば内容が表示されます。
  5. 記録がない日付なら、新規登録として入力できます。
  6. 入力または修正後、「保存する」を押します。

日付を変更しただけでは保存できません。別の日付に保存したい場合は、必ず「読み込む」を押してから入力してください。数値項目を空欄にした場合、既存記録の更新ではその項目の既存値が保持されます。テキスト項目は画面上の編集では空文字として保存できます。

5. サマリーを見る

ホーム上部に、当日の主要指標が表示されます。表示項目は体重、体温、血圧、脈拍です。今日の記録がある場合は今日の記録だけを表示し、記録や入力項目がない場合は -- と表示されます。過去データで補完することはありません。「今日」タブ内にも主要指標の一覧を表示します。

6. 履歴を見る

  1. 「履歴」タブを開きます。
  2. 保存済みの記録が日付順に表示されます。
  3. 各カードで測定値、食事、行動、メモ、更新時刻を確認できます。

更新時刻は端末のローカル時刻で表示されます。

7. 履歴を編集する

  1. 「履歴」タブを開きます。
  2. 編集したい記録の「編集」を押します。
  3. 内容を変更します。
  4. 「更新する」を押します。

数値項目を空欄にした場合、その項目の既存値は保持されます。テキスト項目は画面上の編集では空文字として保存できます。

8. 記録を削除する

  1. 「履歴」タブを開きます。
  2. 削除したい記録の「削除」を押します。
  3. 確認ダイアログで削除を承認します。

削除した記録は元に戻せません。不安な場合は、先にJSONバックアップを書き出してください。

9. グラフを見る

  1. 「グラフ」タブを開きます。
  2. 保存済みデータから折れ線グラフが表示されます。

体重、体温、血圧、脈拍、体脂肪率、基礎代謝量、筋肉量を表示します。血圧は収縮期血圧と拡張期血圧を同じグラフに表示します。データが2件未満の項目は、グラフの代わりに案内メッセージが表示されます。

10. バックアップファイルを保存する

  1. 「バックアップ」タブを開きます。
  2. 「バックアップファイルを保存」を押します。
  3. 表示された画面から端末に保存し、安全な場所で管理します。

ファイル名の例: biolog-mobile-backup-2026-06-26.json。このバックアップは、記録を完全に復元するための正式なJSON形式です。

11. バックアップファイルから復元する

  1. 「バックアップ」タブを開きます。
  2. BioLog Mobileで作成したバックアップファイルを選択します。
  3. 「バックアップファイルから復元」を押します。

同じ日付の記録がある場合は更新されます。読み込みに失敗した場合、途中まで取り込まれることはありません。

12. CSVファイルから記録を取り込む

  1. 「バックアップ」タブを開きます。
  2. CSVファイルを選択します。
  3. 「CSVファイルから記録を取り込む」を押します。

CSVはUTF-8形式を推奨し、1行目はヘッダー行にしてください。

date,weight,temperature,systolic_bp,diastolic_bp,pulse,memo
2026-06-26,62.5,36.6,120,80,72,朝に測定
2026-06-27,62.3,,,,,散歩した

日付,体重,体温,収縮期血圧,拡張期血圧,脈拍,メモ
2026-06-26,62.5,36.6,120,80,72,朝に測定

既存BioLogの一覧タブから書き出したCSVも読み込めます。主な対応ヘッダーは 対象日、体重(kg)、体温(℃)、脈拍(bpm)、基礎代謝(kcal)、体脂肪率(%)、筋肉量(kg)、収縮期血圧、拡張期血圧、メモ、食事ログ、行動ログです。

既存BioLog CSVに含まれる id、ユーザー、記録日時 は読み込めますが、Mobile側の保存対象にはしません。

CSVの注意

  • date または 日付 は必須です。既存BioLog CSVでは 対象日 を日付として扱います。
  • 日付は YYYY-MM-DD 形式にしてください。
  • 同じCSV内に同じ日付が複数ある場合、そのCSVは読み込めません。
  • 既存BioLogのCSVは、Mobileへ取り込む前に1ユーザーに絞ることをおすすめします。複数ユーザーを含むCSVは、同じ日付が重複して拒否される場合があります。
  • 未対応カラムがあるCSVは読み込めません。空の数値セルは保存対象にならず、空白だけのテキストセルは空扱いです。
  • CSVの空テキストセルでは、既存テキストは削除されません。

13. 健康記録をすべて削除する

  1. 「バックアップ」タブを開きます。
  2. 「健康記録をすべて削除」を押します。
  3. 確認ダイアログで承認します。

端末内に保存された健康記録が削除されます。表示設定、同意記録、オフライン利用に必要なアプリ関連データは削除されません。削除前にバックアップファイルを保存することをおすすめします。

14. ライトモード / ダークモードを切り替える

画面右上の「ダーク」または「ライト」ボタンを押します。現在ライトモードの場合は「ダーク」、ダークモードの場合は「ライト」と表示されます。選んだテーマは端末のブラウザに保存されます。

15. オフラインで使う

一度オンラインで開いて準備が完了すると、PWAの画面はオフラインでも起動できます。記録は端末内に保存されます。ただし、初回表示や更新直後はオンライン接続が必要になることがあります。

16. データを移行する

  1. 旧端末でバックアップファイルを保存します。
  2. バックアップファイルを新端末へ移します。
  3. 新端末でBioLog Mobileを開きます。
  4. 「バックアップ」タブからバックアップファイルを使って復元します。

完全な復元には、CSVではなくバックアップファイルを使うことをおすすめします。

17. アプリを消す

BioLog MobileはPWAのため、専用アンインストーラーはありません。ホーム画面のBioLog Mobileアイコンを削除し、必要に応じてブラウザのサイトデータを削除します。サイトデータを削除すると、端末内の記録も消えます。

18. 困ったとき

保存できない

  • ブラウザのプライベートモードで開いていないか確認します。
  • 端末の空き容量を確認します。
  • ページを再読み込みします。

ホーム画面に追加できない

  • AndroidはChrome、iPhoneはSafariで開いてください。
  • 公開URLが正しいか確認してください。

読み込みに失敗する

  • JSONはBioLog Mobileで書き出したバックアップを使ってください。
  • CSVはUTF-8形式、1行目ヘッダーありにしてください。
  • 日付形式が YYYY-MM-DD か確認してください。

画面が古いままに見える

  • 端末をオンラインにし、画面右上の「アプリを更新」を押します。
  • 更新中はアプリを閉じず、自動的に再読み込みされるまで待ちます。
  • それでも変わらない場合は、アプリを完全終了してホーム画面アイコンから起動し直します。
  • 通常の更新では、サイトデータの削除やホーム画面アイコンの削除・再追加を行わないでください。これらの操作では記録が失われる場合があります。
