BioLog Mobile

README.md の内容を読みやすいHTML版として表示しています。原本のMarkdownは変更していません。

概要

BioLog Mobile は、スマホのホーム画面に追加して使える、オフライン対応の健康記録Webアプリです。この仕組みをPWA（Progressive Web App）と呼びます。

利用者側で専用のバックエンドサーバーやDocker環境を用意する必要はありません。GitHub Pagesの公開URLをブラウザで開き、ホーム画面に追加するとアプリのように使えます。

公開状況

このリポジトリは、GitHub上でpublic公開してテスト利用する段階のものです。現時点では正式版ではなく、動作確認、使い勝手の確認、バックアップ運用の確認を目的としています。ベータ版として無料公開しています。

今後、正式版の提供方法や、一部機能の扱いを変更する可能性があります。利用中は定期的に、また機種変更、ブラウザ変更、端末初期化、ブラウザのサイトデータ削除の前には、バックアップファイルを保存してください。

健康記録を含むバックアップファイルやCSVファイルは、GitHubなどの公開場所へアップロードしないでください。

PWAについて

BioLog Mobile はPWAとして作られています。Webアプリですが、スマホのホーム画面にアイコンを追加して、通常のアプリに近い感覚で起動できます。App StoreやGoogle Playからインストールするアプリではありません。

  • 公開URLをブラウザで開き、そのまま利用できます。
  • 同意後、オンライン状態で一度開いて準備が完了すると、アプリ本体の画面をオフラインでも開ける場合があります。
  • 記録データは、利用中のブラウザまたはホーム画面版の端末内に保存されます。
  • サイトデータを削除すると、その保存領域にある記録も削除されます。

アプリを更新する

公開後の最新版を読み込む場合は、オンライン状態で画面右上のライト／ダーク切り替えの下にある「アプリを更新」を押します。確認後に画面が再読み込みされます。入力途中の内容は失われるため、必要な記録を保存してから実行してください。

利用規約・プライバシーポリシーへの同意

初回利用時と、利用規約またはプライバシーポリシーの同意対象版が改定されたときは、内容を確認して同意する必要があります。同意前は健康記録の保存や通常機能、オフライン利用の準備を開始しません。

同意記録は、利用中のブラウザまたはホーム画面版の端末内にだけ保存され、本アプリの機能によって外部へ送信されません。同意しない場合は利用できませんが、端末内に既存の健康記録がある場合も削除されません。同意後も既存記録は維持されます。

健康・医療に関する注意

BioLog Mobile は日々の健康記録を補助するための個人向けツールです。医療行為、診断、治療、助言を目的としたものではありません。

本アプリの表示や記録だけに基づいて、服薬量の調整、受診の要否その他の重要または緊急の健康・医療判断を行わないでください。体調不良、異常値、健康上の不安がある場合は、医師などの専門家に相談してください。

動作保証、データ保存の注意および責任範囲の詳細は、利用規約 と 免責・重要事項 を確認してください。

主な機能

  • 今日の健康記録入力
  • 日付を指定した新規登録、編集
  • 履歴の確認、編集、削除
  • トップ画面の当日主要指標サマリー
  • 体重、体温、血圧、脈拍、体脂肪率、基礎代謝量、筋肉量のグラフ表示
  • ブラウザを利用した端末内保存
  • バックアップファイルの保存、復元
  • UTF-8 CSVファイルからの記録取り込み
  • ライトモード / ダークモード
  • 手動のアプリ更新
  • PWAによるホーム画面追加とオフライン起動への対応

保存されるデータ

記録は、利用中のブラウザまたはホーム画面版の端末内に保存されます。本アプリの現行機能には、入力された健康記録を運営者または第三者へ送信する処理はありません。

トップ画面には、当日の体重、体温、血圧、脈拍、体脂肪率、基礎代謝量、筋肉量を表示します。当日の記録がない場合や未入力の項目は -- と表示され、過去データでは補完しません。

利用しているブラウザまたはホーム画面版に対応するサイトデータを削除すると、その保存領域にある記録も削除されます。機種変更、ブラウザ変更、端末初期化の前には、必ずバックアップファイルを保存してください。

使い始め方

BioLog Mobile は、GitHub Pagesで公開されている公開URLをスマホのブラウザで開いて利用します。通常の利用では、ローカルサーバーを起動する必要はありません。

  1. 公開URLをスマホのブラウザ（AndroidはChrome、iPhoneはSafari）で開きます。
  2. そのままブラウザで使えます。ホーム画面に追加すると、アプリのように起動できます。

Android / Chrome

  1. 公開URLをChromeで開く。
  2. メニューから「ホーム画面に追加」または「アプリをインストール」を選ぶ。
  3. ホーム画面のBioLog Mobileアイコンから起動する。

iPhone / Safari

  1. 公開URLをSafariで開く。
  2. 共有ボタンを押す。
  3. 「ホーム画面に追加」を選ぶ。
  4. ホーム画面のBioLog Mobileアイコンから起動する。

開発者向け：PCブラウザでローカル確認する場合

cd path\to\biolog_mobile
python -m http.server 8787

http://localhost:8787

GitHub Pagesで公開する場合

biolog_mobile の中身をGitHub Pagesで配信します。このアプリは相対パス前提で作られているため、リポジトリ名付きURLでも動作します。

公開対象に含める主なファイルは、index.html、README.html、LICENSE.html、PRIVACY_POLICY.html、TERMS_OF_USE.html、styles.css、consent.js、db.js、form.js、backup.js、charts.js、csv.js、app.js、manifest.webmanifest、service-worker.js、icons/icon-192.png、icons/icon-512.pngです。

健康記録を含むバックアップファイルやCSVファイルは公開しないでください。

バックアップ

バックアップタブからバックアップファイルを保存できます。ファイル名は biolog-mobile-backup-YYYY-MM-DD.json です。内部形式はJSONで、本アプリの記録を復元するために使います。

CSVファイルは外部データの取り込み用です。完全な復元にはバックアップファイルを使ってください。

CSV読み込み

バックアップタブからUTF-8形式のCSVファイルを取り込めます。

対応する英語カラム

date、weight、temperature、systolic_bp、diastolic_bp、pulse、body_fat、bmr、muscle_mass、meal_detail、activity_log、memo

対応する日本語カラム

日付、対象日、体重、体重(kg)、体温、体温(℃)、収縮期血圧、拡張期血圧、脈拍、脈拍(bpm)、体脂肪率、体脂肪率(%)、基礎代謝、基礎代謝量、基礎代謝(kcal)、筋肉量、筋肉量(kg)、食事ログ、行動ログ、メモ

既存BioLogの一覧タブから書き出したCSVにも対応しています。既存BioLog CSVに含まれる id、ユーザー、記録日時 は読み込めますが、Mobile側の保存対象にはしません。CSVの id カラム値は無視され、user_id と date_user は読み込めません。

注意事項

  • 前日からアプリを開いたまま日付が変わった場合は、記録前に「アプリを更新」を押し、「今日」タブの日付が当日であることを確認してください。
  • 「日付編集」で入力した場合は、「今日の記録を保存」ではなく、同じ画面の「保存する」を押してください。
  • 1日1件の記録として保存され、同じ日付を保存または読み込みした場合は既存記録が更新されます。
  • CSV内に同じ日付が複数ある場合、そのCSV全体を読み込みません。既存BioLogのCSVは、Mobileへ取り込む前に1ユーザーに絞ることをおすすめします。
  • 不正なCSVや範囲外の数値がある場合、途中まで取り込まず全体を拒否します。
  • 空のCSVテキストセルでは、既存のテキスト内容は削除されません。

アンインストール相当の操作

PWAのため、専用アンインストーラーはありません。ホーム画面のアイコンを削除しても、ブラウザやOSによっては保存データが残る場合があります。

健康記録、表示設定、同意記録、キャッシュなども削除する場合は、ブラウザまたはOSの設定から対応するサイトデータを削除してください。記録だけを消す場合は、バックアップタブの「健康記録をすべて削除」を使います。

開発方針

  • Vanilla HTML / CSS / JavaScript のみ
  • npm、React、Vue、Vite、Next.js、bundler は不使用
  • 外部CDNは不使用
