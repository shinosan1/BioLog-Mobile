BioLog Mobile 変更履歴

現行版は v0.4.0 Beta です。Markdown版と同じリリース区分で掲載しています。

Unreleased

現在なし。

0.4.0 — 2026-09-30

変更

  • 現行のベータ版を v0.4.0 Beta として明示し、既存の変更履歴をリリース単位に整理。
  • ZIP配布時の日本語ファイル名の互換性を高めるため、docs/司令塔ファイル.md を docs/project_hub.md、docs/スライド.html を docs/slides.html に変更。
  • バージョン表記・文書更新を確実に配信するため、Service Workerの内部キャッシュバージョンを biolog-mobile-v2.13.11 に更新。

修正

  • 保存中に入力を保存前の値へ戻した場合でも、実際に保存された記録を未保存判定の基準に更新し、その入力を未保存変更として保持するよう修正。別日の保存後も今日フォームの入力を保持する回帰テストを追加。
  • 履歴削除にも更新競合チェックを追加し、別タブで更新済みの記録を古い履歴カードから削除できないよう修正。
  • 別日の保存や履歴更新後に「今日」フォームの未保存入力を上書きしないよう修正し、保存処理中に追加入力した内容も未保存のまま保持するよう変更。
  • JSONバックアップ復元時は同日の既存記録をバックアップ内容に合わせて置き換え、バックアップに存在しない測定値が残らないよう修正。CSV取り込みの既存値保持仕様は変更なし。
  • JSONバックアップとCSVの読み込みを厳密なUTF-8デコードに変更し、不正なUTF-8を保存前に拒否するよう修正。
  • Service Workerを版単位のプリキャッシュ優先配信に変更し、新旧資産の混在防止、配置スコープごとのキャッシュ分離、クエリ付き入口のオフライン起動に対応。初回修正時の内部キャッシュ版は v2.13.8、未保存入力修正後は v2.13.9。
  • 補助文書3ページのアイコン参照を ./icons/icon.svg に修正し、操作マニュアルの主要指標サマリー説明を現行7項目・非表示条件に合わせて更新。

0.3.0 — 2026-07-17

変更

  • 今日の主要数値がすべて未入力の場合は「今日の主要指標」を非表示に変更。
  • 今日フォームの入力欄より前にも「今日の記録を保存」ボタンを追加。
  • バックアップ画面と案内文を、バックアップ保存・復元を中心とした表現に変更し、CSV取り込みとの違いを明確化。
  • 7項目のグラフを低くコンパクトな表示に変更。
  • ガイド先頭に「PWAとは」を追加し、利用方法を先に示す構成へ変更。
  • 利用規約とプライバシーポリシーを、意味と同意対象版を変えずに平易化。
  • Service Workerの内部キャッシュバージョンを biolog-mobile-v2.13.4、続いて biolog-mobile-v2.13.5 に更新。

0.2.1 — 2026-07-16

修正

  • 同意対象版更新後もService Workerが古い consent.js を返し、同意画面が繰り返し表示される可能性があった問題を修正。
  • Service Workerの内部キャッシュバージョンを biolog-mobile-v2.13.3 に更新し、同意判定の回帰テストを追加。

0.2.0 — 2026-07-14

追加

  • 初回利用時と利用規約・プライバシーポリシー改定時の同意画面を追加。
  • 最新版を明示的に読み込む「アプリを更新」ボタンを追加。
  • 対象年齢、健康・医療判断に関する注意、問い合わせ時の健康情報記載に関する注意、第三者情報の無断入力禁止などを文書へ追加。

変更

  • 保存場所・外部送信の有無・削除範囲・GitHub Pages利用時の技術情報などの説明を実装に合わせて整理。
  • READMEと操作説明をGitHub Pagesでの一般利用と開発者向けローカル確認に分けて整理。
  • 利用規約・プライバシーポリシーの表現を整理し、公開版の利用範囲と責任範囲を明確化。

修正

  • 同意済みの状態でホーム画面を読み込んだ際、同意画面が一瞬表示される問題を修正。

安全性

  • 同意前は健康記録用IndexedDBを開かず、通常機能とService Worker登録を開始しないよう変更。
  • 同意記録を端末内の localStorage にだけ保存し、外部送信しない構成を明確化。
  • 同意しない場合も既存の健康記録は削除しない仕様を維持。
  • 利用規約・プライバシーポリシーの実質的変更に合わせ、同意対象版を更新。

0.1.0-test — 2026-06-26

追加

  • BioLog Mobile PWAの初期テスト版を追加。
  • Vanilla HTML / CSS / JavaScript構成で実装。
  • manifest / icon / service worker、IndexedDB保存、1日1件の記録、履歴、グラフ、JSONバックアップ、UTF-8 CSV取り込み、ライト/ダーク切替を追加。
  • README.md と OPERATION_MANUAL.md を追加。

安全性

  • 既存BioLog Streamlit / API / SQLite版とは独立した biolog_mobile として作成。
  • Docker、サーバー、npm、外部CDN、外部ライブラリは不使用。
  • 個人データを含むバックアップJSONは .gitignore 対象。
  • CSV importは全件検証後に取り込み、不正CSVは途中まで保存しない。

注記

  • public公開でのテスト利用を想定した段階。
