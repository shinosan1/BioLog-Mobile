# BioLog Mobile

BioLog Mobile は、スマホで使うことを前提にしたオフライン対応の健康記録PWAです。
利用者側で専用のバックエンドサーバーやDocker環境を用意する必要はありません。GitHub Pagesの公開URLをブラウザで開き、ホーム画面に追加するとアプリのように使えます。

## 公開状況

このリポジトリは、GitHub 上で public 公開してテスト利用する段階のものです。
現時点では正式版ではなく、動作確認、使い勝手の確認、バックアップ運用の確認を目的としています。
ベータ版として無料公開しています。
今後、正式版の提供方法や、一部機能の扱いを変更する可能性があります。

利用中は定期的に、また機種変更、ブラウザ変更、端末初期化、ブラウザのサイトデータ削除の前には、JSON バックアップを書き出してください。
健康記録やバックアップJSON、個人データを含むCSVは、GitHubなどの公開場所へアップロードしないでください。

## PWAについて

BioLog Mobile は PWA、Progressive Web App として作られています。
PWA はWebアプリですが、スマホのホーム画面にアイコンを追加して、通常のアプリに近い感覚で起動できます。

App Store や Google Play からインストールするアプリではありません。
公開URLをブラウザで開き、ホーム画面に追加して使います。

同意後にオンライン状態で一度読み込んだ後は、Service Worker によりアプリ本体の画面をオフラインでも開ける場合があります。
記録データは、利用中のブラウザまたはホーム画面版の IndexedDB に保存されます。

公開後の最新版を読み込む場合は、オンライン状態で画面右上のライト／ダーク切り替えの下にある「アプリを更新」を押します。
確認後に画面が再読み込みされます。入力途中の内容は失われるため、必要な記録を保存してから実行してください。

利用しているブラウザまたはホーム画面版に対応するサイトデータを削除すると、その保存領域にある記録も削除されます。
大切な記録は、定期的に JSON バックアップを書き出してください。

## 利用規約・プライバシーポリシーへの同意

初回利用時と、利用規約またはプライバシーポリシーの同意対象版が改定されたときは、内容を確認して同意する必要があります。
同意前は健康記録用の IndexedDB を開かず、通常機能と Service Worker の登録も開始しません。

同意記録は、利用中のブラウザまたはホーム画面版の `localStorage` にだけ保存され、本アプリの機能によって外部へ送信されません。
同意しない場合は BioLog Mobile を利用できませんが、端末内に既存の健康記録がある場合も、その記録は削除されません。
同意後も既存の健康記録は維持され、そのまま利用できます。

## 主な機能

- 今日の健康記録入力
- 日付を指定した新規登録、編集
- 履歴の確認、編集、削除
- トップ画面の当日主要指標サマリー
- 体重、体温、血圧、脈拍、体脂肪率、基礎代謝量、筋肉量のグラフ表示
- IndexedDB による端末内保存
- JSON バックアップ書き出し、読み込み
- UTF-8 CSV 読み込み
- ライトモード / ダークモード
- 手動のアプリ更新
- PWA によるホーム画面追加とオフライン起動への対応

## 保存されるデータ

記録は、利用中のブラウザまたはホーム画面版の IndexedDB に保存されます。
本アプリの現行機能には、入力された健康記録を運営者または第三者へ送信する処理はありません。

トップ画面には、当日の体重、体温、血圧、脈拍、体脂肪率、基礎代謝量、筋肉量を表示します。
当日の記録がない場合や未入力の項目は `--` と表示され、過去データでは補完しません。

利用しているブラウザまたはホーム画面版に対応するサイトデータを削除すると、その保存領域にある記録も削除されます。
機種変更、ブラウザ変更、端末初期化の前には、必ず JSON バックアップを書き出してください。

## 使い始め方

BioLog Mobile は、GitHub Pages で公開されている公開URLをスマホのブラウザで開いて利用します。通常の利用では、ローカルサーバーを起動する必要はありません。

1. 公開URLをスマホのブラウザ（Android は Chrome、iPhone は Safari）で開きます。
2. そのままブラウザで使えます。ホーム画面に追加すると、アプリのように起動できます（手順は下記「スマホでホーム画面に追加する」を参照）。

## スマホでホーム画面に追加する

### Android / Chrome

1. 公開URLを Chrome で開く。
2. メニューから「ホーム画面に追加」または「アプリをインストール」を選ぶ。
3. ホーム画面の BioLog Mobile アイコンから起動する。

### iPhone / Safari

1. 公開URLを Safari で開く。
2. 共有ボタンを押す。
3. 「ホーム画面に追加」を選ぶ。
4. ホーム画面の BioLog Mobile アイコンから起動する。

## バックアップ

バックアップタブから JSON を書き出せます。

ファイル名は以下の形式です。

```text
biolog-mobile-backup-YYYY-MM-DD.json
```

JSON は、本アプリで記録を復元するためのバックアップ形式です。
CSV 読み込みは外部データ取り込み用であり、完全な復元用途には JSON バックアップを使ってください。

## CSV 読み込み

バックアップタブから UTF-8 CSV を読み込めます。

対応カラム:

- `date`
- `weight`
- `temperature`
- `systolic_bp`
- `diastolic_bp`
- `pulse`
- `body_fat`
- `bmr`
- `muscle_mass`
- `meal_detail`
- `activity_log`
- `memo`

日本語カラムにも対応しています。

- `日付`
- `対象日`
- `体重`
- `体重(kg)`
- `体温`
- `体温(℃)`
- `収縮期血圧`
- `拡張期血圧`
- `脈拍`
- `脈拍(bpm)`
- `体脂肪率`
- `体脂肪率(%)`
- `基礎代謝`
- `基礎代謝量`
- `基礎代謝(kcal)`
- `筋肉量`
- `筋肉量(kg)`
- `食事ログ`
- `行動ログ`
- `メモ`

既存BioLogの一覧タブから書き出したCSVにも対応しています。
既存BioLog CSVに含まれる `id`, `ユーザー`, `記録日時` は読み込めますが、Mobile側の保存対象にはしません。

CSV の `id` カラムは読み込めますが、値は無視されます。
`user_id` と `date_user` は読み込めません。

## 注意事項

- BioLog Mobile を前日から開いたまま日付が変わった場合は、記録を入力する前に「アプリを更新」を押し、「今日」タブに表示されている日付が当日になっていることを確認してください。
- 「日付編集」で入力した場合は、「今日の記録を保存」ではなく、同じ画面の「保存する」を押してください。
- 1日1件の記録として保存されます。
- 同じ日付を保存または読み込みした場合は、既存の記録が更新されます。
- CSV 内に同じ日付が複数ある場合、そのCSV全体を読み込みません。
- 既存BioLogからCSVを書き出す場合は、Mobileへ取り込む前に1ユーザーに絞ることをおすすめします。
- 複数ユーザーを含むCSVは、同じ日付が重複してMobile側で拒否される場合があります。
- 不正なCSVや範囲外の数値がある場合、途中まで取り込まず全体を拒否します。
- 空のCSVテキストセルでは、既存のテキスト内容は削除されません。

## アンインストール相当の操作

PWA のため、専用アンインストーラーはありません。

ホーム画面のアイコンを削除しても、ブラウザやOSによっては保存データが残る場合があります。このサイトがブラウザ内に保存した健康記録、表示設定、同意記録、キャッシュなども削除する場合は、ブラウザまたはOSの設定から対応するサイトデータを削除してください。
記録だけを消す場合は、バックアップタブの「健康記録をすべて削除」を使います。
