Glossary

用語解説

BioLog Mobileで使う保存・更新・バックアップに関する主な用語を説明します。

Application

PWA

Progressive Web Appの略です。Webページをホーム画面に追加し、アプリに近い形で使う仕組みです。BioLog Mobileでは、アプリの画面やプログラムを端末に保存してオフライン表示を補助します。

Storage

IndexedDB

ブラウザが端末内に保存するデータベースです。BioLog Mobileでは、健康記録をここに保存します。ブラウザのサイトデータを削除すると、健康記録も削除されることがあります。

Storage

localStorage

ブラウザが端末内に保存する小さな設定領域です。BioLog Mobileでは、ライト・ダークのテーマと、利用規約・プライバシーポリシーへの同意記録を保存します。健康記録の保存先ではありません。

Offline

Service Worker と Cache Storage

Service Workerは、Webアプリの通信とオフライン表示を補助するブラウザ機能です。Cache Storageには、画面、スタイル、プログラム、アイコン、文書などのアプリ資産が保存されます。健康記録はここには保存されません。

更新時は、BioLog Mobile自身の古いbiolog-mobile-キャッシュだけを整理します。

Record

健康記録・日付・date_user

健康記録は、測定値、食事ログ、行動ログ、メモなどをまとめた1件のデータです。BioLog Mobileでは、利用者識別子selfと日付を組み合わせたdate_userを内部的に使い、同じ日付の記録を1件に保ちます。

Backup

JSONバックアップ

アプリが作成する完全復元用のバックアップ形式です。日付、測定値、テキスト項目、作成・更新日時などを含みます。復元時には形式と各項目を確認してから保存します。

Import

CSV取り込み

CSVは表形式のテキストファイルです。BioLog Mobileでは外部データの取り込みに使います。完全な復元にはJSONバックアップを使用してください。

Update

アプリを更新

画面右上の「アプリを更新」は、現在のWebアプリ資産の更新確認と再読み込みを行います。入力途中の内容は失われるため、必要な記録を保存してから実行してください。IndexedDBに保存済みの健康記録を削除する操作ではありません。

Important

保存領域を削除する前に

健康記録、テーマ・同意記録、オフライン用キャッシュ、端末に保存したバックアップファイルは、それぞれ別の場所に保存されます。端末変更、ホーム画面アイコンの削除、ブラウザのサイトデータ削除の前には、JSONバックアップを保存してください。

実装の詳細はコード解説で確認できます。
