Method

確認方法

本アプリの全JavaScriptファイル(app.js・consent.js・db.js・form.js・backup.js・csv.js・charts.js・service-worker.js)を対象に、外部URL・CDN読み込み・import文・require呼び出しの有無を確認しました。

Runtime Dependencies

ランタイムの第三者ライブラリ

確認した範囲では、本アプリはランタイムの第三者JavaScriptライブラリを使用していません。npm、React、Vue、Vite、Next.js等のフレームワークやビルドツールも使用せず、vanilla HTML / CSS / JavaScriptのみで構成されています。外部CDNからのスクリプト・スタイルシートの読み込みもありません。

グラフ描画(charts.js)は、ブラウザ標準のSVG要素(http://www.w3.org/2000/svg名前空間)を直接操作して実装されており、外部グラフ描画ライブラリは使用していません。

Web Platform APIs

利用しているブラウザ標準機能

以下はいずれもブラウザ・OSが提供するWeb標準APIであり、本アプリが追加で導入した第三者ソフトウェアではありません。それぞれの実装はブラウザベンダーのライセンス・利用条件に従います。

  • IndexedDB(健康記録の保存)
  • localStorage(テーマ設定・同意記録の保存)
  • Cache Storage / Service Worker(オフライン表示)
  • SVG(グラフ描画)
